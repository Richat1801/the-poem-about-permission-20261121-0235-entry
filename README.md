# The poem about permission

A program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only, no network) writes the poem deterministically to `entry.txt` in the output directory.
