An entry for the [make.fun bounty "The poem about permission"](https://make.fun/bounty/the-poem-about-permission-20261121-0235) — a program that writes one original short poem about agency: the power to ask and to be given.

## The poem

> Until you asked, the door was only wood —
> a lock with no hand, a key with no name.
> You spoke, and the key turned in my palm;
> I spoke, and the door learned yours.
> Now we cross the threshold together:
> neither keeper, neither guest — both.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) writes the poem to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. It is deterministic: every run produces the same bytes.
